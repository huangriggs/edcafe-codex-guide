來源：已登入的 https://app.edcafe.ai 可見介面，以及本次對話完成的八上第一章＋2-1 測驗。這是網站操作路徑與經驗索引，並非 Edcafe 官方 API 或 CLI。介面更新、帳號方案與教材類型可能改變可用功能；操作前先確認當前畫面。

## 驗證層級

- **已實測流程**：實際完成，且確認操作結果。Quiz 建立、題目修改、Private 儲存、重開核對與資料庫搜尋屬此層級。
- **已確認介面**：實際打開表單、選單或頁面；尚未驗證生成、分享、提交或下載結果。
- **待重測**：已嘗試但沒有取得完成證據。一般Quiz的舊版學生預覽與Word下載仍待重測；Chatbot教師Preview已試聊。

## 12 種建立工具

共同入口：**Create New → 工具名稱**。下表網址的 `type` 是本次逐一打開表單觀察到的值；`fo` 為資料夾 ID，`from` 為返回來源，應由目前介面取得，不要猜 ID。

共同來源四分頁（下表標示「四來源」）：Topic、Text、Webpage、Files。Quiz 的 Files 表單標示文件／圖片、每個檔案最大 50MB；其他工具限制以各自當前表單為準。上傳前先確認來源與使用者授權。

| 工具 | 建立路徑 | 輸入與設定 | 建議用途與驗證 |

## 已實測的數學測驗流程

1. 先依課本 PDF 核定年級與小節，題目、答案、詳解在本機分離保存。教材「第一章＋2-1」不能只憑章節代號猜內容。
2. 在目標資料夾 Create New → Quiz，使用 Text 放入已審核的題幹、四選項、正解與詳解。選 Multiple Choice、10 題、Chinese (繁體中文)。附加要求寫清楚基礎比例、範圍、不加入超範圍內容。
3. Generate Quiz。生成會逐步出現；Save 尚未可用時，先觀察生成狀態。
4. 生成後逐題核對。**即使要求保留選項順序，AI 仍曾重排選項**；必須以最後實際四選項與正解 radio 為準。
5. 數學用 `$...$` LaTeX，例如 `$x^2+6x+9$`、`$\sqrt{36}$`。DOM 中 KaTeX 可含語意與視覺兩套文字，不能只因快照重複就判定畫面重複；需要時看截圖。
6. Quiz Introduction 可展開並修改 rich text 作答說明。學生識別要求使用班級代號＋座號；未驗證平台欄位能否完全限制真實姓名。
7. Save → File name → 選目標資料夾 → Content Visibility。當日測試帳號的 Default file visibility 為 **Public**（其他帳號請現場確認）；未要求發布時逐份選 **Private**，不要誤存社群教材庫。
8. Save 後確認教師教材頁、標題與資料夾，再 Edit 重開核對題目與正解。若返回時詢問 Discard changes，只在確認沒有需要保存的新修改時使用 Discard。

實測成果在 `examples/quiz-g8/`；公開套件不含原帳號教材ID。它是現有正式教材，探索索引時未變更題目或建立假學生提交。

## Assign、Share 與 Report 的差別

| 入口 | 作用／本次可見設定 | 教學建議（依介面描述推論） |
|---|---|---|
| Assign → Classic | Form-based quiz with summary at the end | 一次看全份題目並於結束看統整，適合一般練習 |
| Assign → Practice | Instant feedback after each question | 逐題立即回饋，較適合首次練習與補救 |
| Assign → Assessment | One question at a time, feedback at the end | 逐題呈現、最後回饋，較適合檢核 |
| Assign 其他設定 | Accepting submissions、Shuffle questions、Set time limit；QR／Copy link／Embed；Google Classroom／Microsoft Teams；Preview | 務必檢查現況，並由學生端測一題後才正式派發 |
| Share → View Content | 僅檢視內容 | 給同事看教材 |
| Share → View Content & Submissions | 可檢視教材與提交資料 | 分享前確認對象與資料需求 |
| Share → Clone Content | 讓他人儲存教材副本 | 讓同事修改自己的版本 |
| Report → Participants／Questions | 作答者統計／逐題選項作答分析；頁面明示只記錄每位參與者的第一次提交 | 用真實作答後的題目分析決定補救重點 |

本次只開啟設定與選單，未切換模式或提交開關。現有測驗的 Accepting submissions 已是 ON，**不是開啟 Assign 就新啟用**。未實測題數配分、學生開始／提交、學生姓名機制、三種模式的完整作答行為或計時到期行為。

## 加速操作與避免誤點

這份索引讓下一次直接知道「目的 → 工具 → 表單 → 結果檢查」，節省重複探索。它不能保證網站每次速度相同；沒有做前後耗時基準比較。

- 優先以目前 DOM 的角色、標籤與按鈕名稱定位。Create New 在 Library 可能出現兩次；先確認後限定頁面區域或 `.first()`。
- 切換建立頁可能先出現 **Discard your creation?**，即使只開過空白表單；若確實沒有輸入需要保存的內容，Discard 後才會出現 Create New 選單。
- 不預設所有工具標題都是 Create；Teaching Resources 實際是 **Find Teaching Resources**。Library 的標題是 **My library**，大小寫不同。
- 按下按鈕後網址和 DOM 可能稍後才切換；先等已觀察到的目標控制可見，或再取一次狀態，避免對舊畫面下指令。
- Quiz 選項欄位取得焦點後 placeholder 會變成 **Press [TAB] to generate**。不要用會縮減的 placeholder 結果陣列固定索引批次填寫；先讀取當前 DOM，再按 `textarea` 的穩定 `name` 填寫。
- 正解確認讀取原生 radio 的 `checked`，不要只讀 `aria-checked`。保存後重開核對才算完成。
- 打開選單不等於實測完功能；下載也必須取得真實檔案並能開啟。

## 建議的數學課搭配

先用 Flashcards 整理「平方根」與「算術平方根」差別，再用 Practice 測驗練習；檢核時使用 Assessment；有作答後用 Questions 找錯誤選項。這是依工具介面做的教學建議，Flashcards 與學生模式尚未完整實測。精準數學題仍先本機審題，再送入 Quiz，避免生成後逐題重做。

## 索引維護與再次使用

- 下次可說：「使用 edcafe-operations 操作索引，幫我……」。技能位置：`skills/edcafe-operations/SKILL.md`；新對話是否自動出現在技能清單取決於載入時機，也可直接指定路徑讀取。
- 搜尋資料：`操作資料.json` 是按目的整理的索引；`建立表單觀察.json` 是建立表單證據。
- 本機查詢：`powershell -File .\專案文件\Edcafe操作索引\查詢操作.ps1 -關鍵字 測驗`。只搜尋本機索引，不會登入或操作網站。
- 網站改版後，以新畫面更新日期、路徑、欄位與驗證層級；完成新成品再補結果。不要保存 cookies、密碼、token、預覽參數或學生姓名。
- 下一輪優先補測：學生 Preview 載入 → 一份明示測試用的私有測驗完成作答 → 真實匯出檔案；再依實際教學需求補 Flashcards／Chatbot 成品，不為探索而大量生成。
