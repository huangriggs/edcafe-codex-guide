# 困難、修正與注意事項

本表源於當日實測，不把特定帳號或一次錯誤當普遍規則。

| 困難 | 當時觀察 | 下次做法 |
|---|---|---|
| AI重排選項 | 原稿答案字母與生成題不同 | 核對最後四選項、radio checked，保存後重開全部正解 |
| 欄位定位變動 | 聚焦後placeholder改成Press [TAB] to generate | 讀當前DOM，用穩定name；不用會縮減的匹配陣列位置 |
| 畫面過渡 | 點擊後快照短暫仍是舊頁 | 等已觀察的目標控制出現、重新觀察，不盲目重點 |
| 剪貼簿焦點競態 | 填入時目標input失去焦點 | 先看目前DOM，明確點輸入框後再填，不加無限重試 |
| 空白草稿捨棄 | 換工具仍跳Discard your creation | 先確認無需保存內容，才Discard |
| 保存可見性 | 當日帳號預設Public | 每份教材看Save對話；未要求公開選Private，不改全站設定 |
| 公式DOM重複 | KaTeX有語意／視覺兩套文字 | 看實際畫面再判斷，不能只憑快照重複認定排版錯 |
| 一般Quiz Preview載入 | 早期只見載入圖示 | 保留待重測，不推論所有Preview失效；後來Chatbot Preview可試聊 |
| Word下載 | 兩次看見匯出視窗，下載事件逾時 | 要真實取得及開啟檔案才算完成；先保存本機可編輯內容 |
| 影片缺CC | 官方文章描述有衝突，當前表單要求CC | 以現行表單及實測為準；硬字幕另上SRT為CC |
| 字幕不自然 | 固定字數切段造成破句 | 依語意及標點，人工核對文字、同步和最終畫面後才上傳 |
| 字型缺字 | 負號等符號可能缺字 | 檢查字型及實際畫格，避免只看腳本 |
| AI語音／ASR | 數學讀法難，ASR有同音字或幻覺 | 用核定腳本做字幕，實聽公式；ASR只是核對輔助 |
| 模式混用 | YouTube Quiz Assign無一般三模式 | 先看該工具當前對話，不套用其他工具設定 |
| Chatbot首問給答案 | 初版先說√25=5且連問 | 加具體正反範例，實際再試，不能只寫友善／不要直接答 |
| Chatbot假設不正確 | 曾說其他單元超出八年級或措辭反轉平方關係 | 明確只說本教練範圍；正確關係寫5²=25並重測 |
| Chatbot仍偏離 | 開放式情境連問，卡住後示範不足 | 保留失敗；教師陪同，必要時接手，嚴格流程用固定教材設計 |
| 回覆證據截斷 | Copy message已出現但文字仍串流 | 確認完整末句或最後狀態；截斷紀錄標有限證據 |
| 索引累積後過時 | 前段表格與後段更新不同 | 發布前同步主表、JSON、skill參考文件，不只追加腳註 |

## 每項產出的最小完成檢核

- Quiz：年級／來源、題幹／選項／答案／詳解一致，唯一答案，保存重開。
- 影片：內容、聲音、動態、字幕時間與語意、實際缺字／遮擋，先QA後上傳。
- YouTube Quiz：CC可用、題目由影片支援、保存重開，學生入口與提交分開驗證。
- Chatbot：首問、錯誤訂正、新題、範圍、卡住與支持語氣實測，標偏離。
- 匯出：檔案收到且開啟可讀；Word公式可編輯性與PPT版面另驗證。

公開repo是一個可改作的教師包。不要公開自己的學生資訊、原教材掃描、帳號截圖、private教師頁或不透明分享參數。只有教學內容需上傳平台，來源PDF是否可上傳要看授權與任務。

公開打包時新增發現：Windows PowerShell 5.1可能把沒有BOM的UTF-8中文PS1誤讀成系統編碼；本套件PS1保留UTF-8 BOM，JSON仍明確按UTF-8讀取。PowerShell 7與Python使用者也可直接用離線查詢。
