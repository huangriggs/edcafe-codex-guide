# 製作影片：預設使用 edge-tts

給其他使用者的預設旁白工具是 [edge-tts](https://github.com/rany2/edge-tts)。它透過 Microsoft Edge 的線上語音服務產生聲音，不需安裝 VoxCPM2 模型或具備 GPU；需要 Python、網路及可用的線上服務。旁白文字會送至該服務，請使用已核定可對外處理的教學稿，不含學生個資。

## 先生成短段

建議用獨立虛擬環境。以下 PowerShell 指令於自己的影片工作資料夾執行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install edge-tts
.\.venv\Scripts\python.exe -m edge_tts --list-voices
.\.venv\Scripts\python.exe -m edge_tts --voice zh-TW-HsiaoChenNeural --rate=-10% --text "每個人都可以展現不同特質，不必符合相同的性別樣貌。" --write-media preview.mp3 --write-subtitles preview.srt
```

2026-10-04 已連線核對 `zh-TW-HsiaoChenNeural`、`zh-TW-HsiaoYuNeural`、`zh-TW-YunJheNeural` 三種台灣華語聲音。名稱與服務可用性日後仍須用 `--list-voices` 確認。本次性別平等影片採 HsiaoChen、速度 -10%，28句完成合成；不代表所有人的網路環境都可連線。

較長稿可使用 UTF-8 檔案：

```powershell
.\.venv\Scripts\python.exe -m edge_tts --voice zh-TW-HsiaoChenNeural --rate=-10% --file narration.txt --write-media narration.mp3 --write-subtitles narration.srt
```

先實聽短段，檢查數字、專有名詞與語速，核定後再做完整旁白。公式與符號可另寫成適合朗讀的文字。工具輸出的字幕仍需檢查；不能把原範例的 SRT 時間直接套進新的音軌。

## 影片與字幕驗收

1. 使用 Python／Pillow 或自己可用的影片工具編排分鏡；FFmpeg 負責合成 MP4。edge-tts 只產生語音及字幕，沒有製作動畫。
2. 先做短預覽，核對繁體字型、動畫、字幕可讀性及影音同步。
3. 拼接段落、改語速或加入思考停頓後，重新計算字幕時間；保留核定稿、音軌、SRT、時間軸和可編輯程式。
4. 檢查最終影片的文字、斷句、同步、缺字及實際畫格。ASR 是輔助證據，辨識不確定的詞仍需實聽。
5. 依使用者授權上傳 YouTube；再上傳帶時間碼 SRT，確認 CC 已發布且播放器可選「中文（繁體）」。燒錄字幕不能代替 CC。
6. 最後使用 Edcafe YouTube Quiz，逐題核對、保存 Private、重開，再用合成身份測試學生入口與教師報告。

## 已有本機模型時

VoxCPM2 是原作者電腦已配置的**選配**工具，原平方根影片以它製作。公開 repo 沒有附模型、GPU 環境或原音軌，也不要求其他使用者安裝它。只有使用者已具備且希望採用該環境時，才沿用本機模型；否則依本頁的 edge-tts 流程。
